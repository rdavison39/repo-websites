RYLEE WEBSITE REFRESH
---------------------
Open index.html in a browser to view the site.

This is a static website; it does not require installation or a server.
The ZIP contains clean, short, ASCII-only file names and excludes legacy
FrontPage metadata, temporary files, Photoshop source files, and obsolete
video-editor project files. Original photos, source video clips, and the archived music file are retained.

Video clips are kept in their original .MTS and .WMV formats. Browser
support for .MTS varies; download and play with VLC if necessary.

The old schedule and academic notes are presented as historical archive
content because the source site was last updated in 2017.
