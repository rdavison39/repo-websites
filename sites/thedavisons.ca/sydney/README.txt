SYDNEY WEBSITE - CLEANED STATIC VERSION

Open index.html in a web browser. This is a static site and does not require installation or a server.

Pages: Home, About Sydney, My Team, Schedule, Photos, Videos, Academics.

The site content is an archive of the original site, last updated September 4, 2015. Schedules, team details and academic information are historical.

Filenames have been shortened and normalized for easier cloud backup. Legacy FrontPage metadata, temporary files, old web templates, Photoshop source files and video-editor project files were omitted. Original raster photos, logos and video footage were retained where relevant. The MTS and WMV video files have not been converted; playback depends on the software used.
